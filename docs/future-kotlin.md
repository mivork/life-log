# 将来展望: Kotlin ネイティブ拡張メモ

目的は「将来のモバイルアプリ展開への拡張性を担保する」ことのみで、現時点では実装しない。

## 想定する形
- Android アプリ（Kotlin / Jetpack Compose）で、記録入力の導線をホーム画面ウィジェットや通知リマインドから最短化する。
- データ形式は Web 版と同一の data.json スキーマ v1 を正とし、アプリはその読み書きアダプタを持つ。
  スキーマをアプリ都合で分岐させない（分析エンジン Python がそのまま読める状態を維持する）。
- 同期は Go 同期ツールと同じ考え方（検証 → プライベートリポジトリへコミット、デフォルト dry-run 相当の確認ステップ付き）を踏襲する。
- 暗号化が必要になった場合は Rust/WASM 版と同一仕様（Argon2id + AES-256-GCM、出力フォーマット互換）を Kotlin 側でも実装し、相互に復号できることをテストで担保する。

## 着手条件
- Web 版（Phase 1〜3）が日常運用に入り、記録の継続が安定してから検討する。
- アプリ固有の新項目を足したくなったら、先にスキーマの version を上げる手続きを合意書側に記録する。
